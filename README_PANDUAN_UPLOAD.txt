E-PORTOFOLIO PPL MANDIRI V14.75 — SIAP GITHUB PAGES

Isi paket:
- index.html : halaman utama e-portofolio
- assets/media/ : foto, ilustrasi, logo, dan gambar latar yang digunakan di HTML
- .nojekyll : menonaktifkan pemrosesan Jekyll agar GitHub Pages menyajikan file langsung

PENTING: Ekstrak ZIP terlebih dahulu. Jangan hanya mengunggah file ZIP ke repositori.

Cara deploy melalui situs github.com:
1. Buat atau buka repository GitHub Pages yang ingin digunakan.
2. Klik Add file > Upload files.
3. Unggah index.html, folder assets (dengan seluruh subfolder dan isinya), serta .nojekyll dari folder hasil ekstraksi. File panduan tidak wajib diunggah.
4. Commit changes.
5. Buka Settings > Pages, atur Deploy from a branch, pilih branch main dan direktori /(root), lalu Save.
6. Setelah publikasi, buka situs GitHub Pages Anda dan cek bahwa foto, galeri, tombol, serta tautan tampil.

Jangan ubah nama folder atau pindahkan gambar tanpa mengubah alamatnya di index.html.
Semua file yang dibutuhkan dapat diunggah melalui GitHub Web karena tiap file berukuran kurang dari 25 MB.
